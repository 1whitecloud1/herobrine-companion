# 觉醒怪物对白生成示例 (Zombie, Skeleton, Creeper, Spider, Enderman, Witch & Hero)

由于全量 16 个族群的交叉矩阵对白极其庞大，此处为你呈现包含 `zombie`、`skeleton`、`creeper`、`spider`、`enderman` 和 `witch` 基础及部分目标互聊矩阵，以及 `hero_reply` 全局回复的样例文件。所有台词均经过手工精调，符合各族群独一无二的阴森感与克制的黑色幽默，并完全遵守 JSON 格式及占位符要求。
